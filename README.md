# Arise & Shine Early Learning Centre

A responsive website for Arise & Shine Early Learning Centre in Rustenburg, South Africa.

## Pages

- `index.html` — centre overview, values and quick contact details
- `about.html` — mission and educational approach
- `programs.html` — programs and age groups
- `admissions.html` — enrolment steps and admissions guidance
- `contact.html` — contact details, inquiry form and location map

## Run locally

No build step or external framework is required. Open `index.html` in a browser, or serve this folder with any static web server.

The inquiry form opens a prefilled WhatsApp message for the family to review and send. Google Maps and WhatsApp links require an internet connection.

## Images

The centre logo and website photos are stored in the repository root and referenced directly by the pages.
